# Repository Agent Guidelines

Planning documents and issue labels do not authorize implementation. Obtain
explicit implementation approval before changing application code.

## Agent skills

### Issue tracker

Issues and PRDs live in GitHub Issues for `invariantengineering/lexlatam-voice-agent`.
See [issue tracker conventions](docs/agents/issue-tracker.md).

### Triage labels

Use the default five triage roles and matching label names.
See [triage labels](docs/agents/triage-labels.md).

### Domain docs

Use one repository-level context and architecture decision record directory.
See [domain documentation conventions](docs/agents/domain.md).
